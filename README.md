# Bản tin

App Android đọc tin Việt Nam và thế giới từ VnExpress, Quân đội Nhân dân và Tuổi Trẻ, kèm widget màn hình chính.

- Màn hình app: hai tab Việt Nam / Thế giới, chạm vào tin để xem ảnh và tóm tắt, nút "Đọc bài gốc" mở bài trên báo.
- Widget: danh sách tiêu đề mới nhất có ảnh nhỏ, chạm để mở bài, nút làm mới.

File APK được GitHub Actions tự đóng gói mỗi lần có thay đổi; tải ở mục **Releases**.
